Roadmap

00 — Stabilize

Restore a trustworthy floor

  • Make the full local suite green.
  • Label the current compiler experimental.
  • Fail explicitly on unsupported behavior; never fail open.
Gate: 0 failing tests and a published supported-feature matrix.
01 — Syntax

Build a thin scanner/parser CLI

  • Dispatch correctly for TS, TSX, JS, and JSX.
  • Return exact diagnostic codes, ranges, order, and exit status.
  • Compare every declared case with the pinned Go oracle.
Gate: 100% syntax-diagnostic parity on the declared corpus.
02 — Transpile

Ship the first useful artifact

  • Single-file, true --noCheck path.
  • ESNext output, preserved ESM, type erasure.
  • One JSX mode; no config, declarations, maps, build, watch, or LSP.
Gate: exact representative emit corpus, Node runtime checks, median/p95/RSS benchmark.
03 — Project

Add only common project behavior

  • TS-only projects, basic tsconfig, relative imports.
  • Node10 resolution and modern JavaScript output.
  • Test on representative real repositories.
Gate: equivalent graph, diagnostics, and deterministic output versus Go.
04 — Semantics

Rebuild from binder fundamentals

  • Correct AST kinds and binder control-flow graph.
  • Primitives, visibility, definite assignment, arrays, tuples, and unions.
  • Add .errors, then .types/.symbols gates.
Gate: no false negatives in the strict corpus; no size-based checker bypass.
